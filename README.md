## 1. نظرة عامة على النظام
هذا المشروع عبارة عن **بوابة هوتسبوت تفاعلية حديثة (Responsive SPA Hotspot Captive Portal)** مصممة للعمل بكفاءة وسرعة فائقة على راوترات المايكروتك (MikroTik RouterBOARD / Cloud Core Routers).

### 🌟 أبرز المميزات:
- **تطبيق صفحة واحدة (Single Page Application - SPA)**: انتقال فوري بين شاشات تسجيل الدخول، الأسعار، نقاط البيع، وحالة الاتصال دون إعادة تحميل الصفحة.
- **تكامل تام مع متغيرات المايكروتك**: استخدام استجابات JSON خفيفة عبر AJAX عبر قوالب المايكروتك (`$(username)`، `$(bytes-in)`، `$(bytes-out)`، `$(remain-bytes-total)`، `$(domain)`، `$(uptime)`، إلخ).
- **لوحة تحكم إدارية مدمجة (`dash.html`)**: لتعديل اسم الشبكة، الأسعار، السرعات، نقاط البيع، وتوليد ملف `config.js` بضغطة زر.
- **إدارة ديناميكية للسرعات**: يختار المستخدم سرعته المفضلة قبل الدخول أو يقوم بتغييرها مباشرة بعد تسجيل الدخول دون فقدان رصيد الكرت.
- **عزل وإيقاف تحديثات جوجل والتطبيقات**: خيار لتوفير رصيد الباقة ومنع استهلاك البيانات في الخلفية.
- **نظام حماية ضد التخمين (`hotBlocker`)**: حظر المستخدم مؤقتاً بعد 10 محاولات خاطئة مع عداد تنازلي.
- **زر إرسال الخطأ عبر SMS**: عند إدخال كرت خاطئ أو منتهي، يتم تجهيز رسالة نصية SMS برقم الكرت ونوع الخطأ مرسلة مباشرة لرقم إدارة الشبكة (`+967779744206`).
- **حفظ الكروت السابقة**: حفظ آخر 5 كروت في القائمة المنسدلة للرجوع إليها بسهولة.

## 4. لوحة التحكم الإدارية (`dash.html`)

صفحة `dash.html` هي لوحة تحكم مستقلة رسومية موجهة لمدير الشبكة بدون الحاجة لخبرة برمجية:

### وظائف لوحة التحكم:
1. **تعديل البيانات الأساسية**:
   - اسم الشبكة (`siteName`).
   - نص وشريط الإعلانات المتحرك (`textSlider1`).
   - رسالة الترحيب المنبثقة وتفعيلها أو إيقافها.
   - نص قسم العروض الخاصة (`offers`).
2. **إدارة جدول السرعات (`Speed Table`)**:
   - إضافة سرعة جديدة، تعديل اسم السرعة الظاهر للمستخدم (مثل: "سرعة الألعاب").
   - تحديد قيمة السرعة في المايكروتك بصيغة `Upload/Download` مثل `2M/10M` أو تركها فارغة للسرعة الافتراضية للبروفايل.
   - تعيين السرعة الافتراضية (`selected`) عبر Radio Button.
   - حذف أي سرعة غير مرغوبة.
3. **إدارة باقات وأسعار الكروت (`Packages`)**:
   - إضافة وحذف كروت، تحديد السعر، الحجم بالميجا/الجيجا، وفترة الصلاحية والوقت.
4. **إدارة نقاط البيع (`Sales Points`)**:
   - إضافة المحلات والبقالات وعناوين تواجد الكروت.
5. **توليد وتحميل الملف (`saveChanges()`)**:
   - عند الضغط على زر **"تحميل الملف"**، تقوم اللوحة بتجميع كافة المدخلات وتوليد كود `config.js` نظيف وجاهز، ثم تنزيله تلقائياً إلى جهازك لتضعه في مجلد الهوتسبوت في المايكروتك.

## 5. آلية المصادقة والتوافق مع MikroTik RouterOS

تعتمد الصفحة على تقنية **AJAX JSON Polling & Seamless Handshake** المتوافقة تماماً مع سيرفر الهوتسبوت:

```
+-----------------------------------------------------------------------------------+
| 1. المستخدم يفتح الصفحة: يتم إرسال طلب AJAX إلى /login?var=callBack               |
|    - إذا كان غير متصل: يرد قالب login.html بكائن JSON:                            |
|      { "logged_in": "false", "action": "onLoginStart" }                           |
|    - يتم فحص الكوكيز (hotCookie)، وإذا وُجد كرت محفوظ يتم تسجيل دخوله فوراً.      |
+-----------------------------------------------------------------------------------+
                                       |
                                       v
+-----------------------------------------------------------------------------------+
| 2. تسجيل الدخول اليدوي:                                                           |
|    المستخدم يكتب الكرت، يختار السرعة، ويضغط "دخول الإنترنت":                       |
|    يتم إرسال طلب GET:                                                             |
|    /login?username=USER&password=PASS&domain=SPEED|GOOGLE_MODE&var=callBack       |
+-----------------------------------------------------------------------------------+
                                       |
                   +-------------------+-------------------+
                   |                                       |
          [في حال نجاح الدخول]                    [في حال فشل الدخول]
                   |                                       |
                   v                                       v
+------------------------------------+   +------------------------------------+
| 3. يرد المايكروتك عبر alogin.html:  |   | 3. يرد المايكروتك عبر login.html:  |
| { "logged_in": "true",             |   | { "error": "not found",            |
|   "action": "onLoggedIn" }         |   |   "action": "onLoginError" }       |
|                                    |   |                                    |
| - يتم إخفاء شاشة الدخول.           |   | - تشغيل مترجم الأخطاء العربي.       |
| - إظهار شاشة الحالة (#status).     |   | - إظهار نافذة الخطأ المنبثقة.      |
| - بدء استعلام الحالة كل ثانية:     |   | - توليد زر SMS لإرسال الخطأ للإدارة|
|   /status?var=callBack             |   | - زيادة عداد المحاولات الفاشلة.    |
+------------------------------------+   +------------------------------------+
```

### قوالب المايكروتك:
- **`login.html`**:
  ```html
  $(if var == "")
  <script>window.location.href="index.html"</script>
  $(else)
  $(if error == "")
  {"logged_in": "$(logged-in)", "link_only": "$(link-orig-esc)", "link_login_only": "$(link-login-only)", "action": "onLoginStart"}
  $(else)
  {"logged_in": "$(logged-in)", "error": "$(error)", "action": "onLoginError"}
  $(endif)
  $(endif)
  ```
- **`status.html`**:
  يغذي شاشة المستخدم ببيانات الرفع، التحميل، المتبقي، الوقت المستهلك، وسرعة الكرت الحالية.

## 6. نظام تحديد السرعات وتغيير السرعة أثناء الاتصال

### أ) عند تسجيل الدخول الأول:
يختار المستخدم السرعة من القائمة (مثلاً `2M/7M`). يتم تمرير هذه القيمة عبر معامل `domain` في رابط تسجيل الدخول:
```
/login?username=123456&domain=2M/7M|*no**&var=callBack
```
يقوم راوتر المايكروتك (عبر ميزات User Profile أو On-Login Scripts التي تقرأ قيمة `$(domain)`) بتطبيق قيود السرعة المقابلة على المستخدم في `Queue Simple` أو `Rate-Limit`.

### ب) عند تغيير السرعة أثناء الاتصال من شاشة الحالة (`#status`):
إذا قام المستخدم بتغيير السرعة في القائمة المنسدلة (`#spes`):
1. دالة `loginst(speed, googleToggle)` توقف فوراً الاستعلام الدوري (`$statusflag = false`).
2. تقوم بإرسال طلب خروج صامت وسريع `/logout`.
3. تقوم بتحديث الكوكيز بالسرعة الجديدة المختارة.
4. بعد مهلة 500 ميلي ثانية، ترسل تلقائياً طلب تسجيل دخول جديد بنفس الكرت ومعامل السرعة الجديد:
   ```javascript
   syy(username, "", newSpeed + "|" + googleToggle);
   ```
5. يتم ربط المستخدم بالسرعة الجديدة دون أي حاجة لإعادة كتابة الكرت أو فقدان جلسته.

## 7. ميزة إيقاف تحديثات جوجل (Google Updates Blocker)

- **الهدف**: منع متجر Google Play وتحديثات النظام والتطبيقات من استهلاك باقة ورصيد الكرت في الخلفية فور الاتصال بالشبكة.
- **أزرار التحكم**:
  - `toggleBtn` في شاشة تسجيل الدخول.
  - `toggleBtn2` في شاشة حالة الاتصال.
- **القيم الممررة**:
  - `*no**`: ميزة إيقاف التحديثات **مُلغاة** (التحديثات تعمل بشكل طبيعي).
  - `*yes**`: ميزة إيقاف التحديثات **مفعلة** (يتم منع التحديثات).
- **التوافق مع المايكروتك**: يتم إرسال القيمة مدمجة مع السرعة في حقل `domain` (مثل `2M/7M|*yes**`). في المايكروتك، يمكن برمجة سكربت الهوتسبوت لإضافة IP المستخدم تلقائياً إلى `Address List` خاصة بقواعد الفايروول (`Firewall Filter / Raw / Mangle`) لحظر نطاقات وسيرفرات Google Update أو تخفيض أولويتها.

## 8. معالجة الأخطاء ونظام الإبلاغ الفوري عبر الرسائل (SMS)

عند فشل الدخول أو حدوث مشكلة في الكرت، تقوم دالة `toArabicError(error)` بفحص كود الخطأ القادم من المايكروتك وترجمته بدقة إلى رسالة مفهومة للمستخدم:

| الخطأ في المايكروتك | الرسالة المعروضة للمستخدم |
| :--- | :--- |
| `invalid username or password` / `not found` | **لقد ادخلت اسم المستخدم بطريقة غير صحيحة، الرجاء المحاولة مرة اخرى** |
| `uptime limit reached` / `No more online time` | **عذراً لقد انتهى الوقت المتاح لك** |
| `traffic limit` / `transfer limit reached` | **لقد انتهى رصيد هذا الكرت😭** |
| `no valid profile found` | **لقد انتهت صلاحية هذا الكرت** |
| `invalid Calling-Station-Id` | **هذا الكرت مقترن بجهاز آخر !** |
| `user ... already logged in` | **هذا الكرت مستخدم حالياً على جهاز آخر** |
| `server is not responding` | **يرجى الانتظار، يتم الآن اعادة تشغيل الشبكة، هذه العملية قد تستغرق بعض الوقت** |
| `web browser did not send` | **يرجى محاولة ادخال الكرت مرة اخرى** |

### 📲 زر إرسال الخطأ عبر SMS:
داخل صندوق الخطأ المنبثق، يتم تلقائياً إنشاء زر:
```html
<a href="sms:+967779744206?body=حصل خطأ: [نص الخطأ] ----- رقم الكرت [رقم الكرت]">
  <button class="app-submit">إرسال الخطأ</button>
</a>
```
- **الفائدة**: عند ضغط المستخدم على الزر، يفتح تطبيق الرسائل النصية بهاتفه مباشرة مع تعبئة رقم خدمة العملاء والدعم الفني (`+967779744206`) وتجهيز نص الرسالة متضمناً رقم الكرت ونوع الخطأ بدقة دون الحاجة لكتابته يدوياً من قِبل العميل.

## 9. أنظمة الحماية وتحسين الإدخال والكوكيز

### 1. نظام الحظر ضد التخمين (`hotBlocker.min.js`):
- يتم تفعيله عبر الخصائص: `block-time="2"` (مدة الحظر بالدقائق)، `try-count="10"` (عدد المحاولات المسموحة)، `enable-hot-blocker`.
- عند تجاوز 10 محاولات خاطئة متتالية، يتم تخزين وقت الحظر في الكوكيز وتوجيه المستخدم لشاشة الحظر (`#block`).
- تعرض شاشة الحظر رسالة: **"أنت محظور: تم حظرك بسبب تجاوز الحد المسموح من المحاولات الخاطئة"** مع عداد تنازلي بالدقائق والثواني.

### 2. تحسين وتنسيق الإدخال (`hotInImprover.min.js`):
- `to-arabic-numbers`: تحويل الأرقام المكتوبة بالأرقام العربية/الهندية (٠-٩) تلقائياً إلى الأرقام الإنجليزية (0-9)، وتحويل النقطتين `:` إلى `0`.
- `rm-white-spaces`: إزالة المسافات التي قد تنشأ عند نسخ ولصق رقم الكرت.
- `localStorage`: حفظ آخر 5 كروت تم استخدامها على الجهاز وعرضها في القائمة المنسدلة `#usernamesList`.

### 3. حفظ الجلسة والكوكيز (`hotCookie.min.js`):
- حفظ بيانات الكرت لمدة تصل إلى 15 يوماً للدخول التلقائي عند الاقتراب من الشبكة.
- زر تسجيل الخروج (`clear-hot-cookie`) يمسح الكوكيز المسجلة ويمنع الاتصال التلقائي غير المرغوب به.

## 10. واجهة المستخدم والشاشات التفاعلية

تتكون الصفحة الرئيسية من 4 تطبيقات/شاشات فرعية تعمل كـ Single Page Application:
1. **شاشة تسجيل الدخول (`.login`)**:
   - شعار الشبكة وحالة الاتصال.
   - حقل رقم الكرت مع ماسح الباركود/QR، وقائمة الكروت المحفوظة.
   - قائمة اختيار السرعة ومفتاح إيقاف التحديثات.
   - أزرار سريعة للانتقال لصفحة "أسعار الكروت" و"أماكن البيع".
2. **شاشة أسعار الكروت (`#price`)**:
   - عرض باقات الساعات والأيام بالأسعار والأحجام المستوردة من `config.js`.
   - بطاقة العروض الخاصة.
3. **شاشة أماكن ونقاط البيع (`#sell-point`)**:
   - استعراض أسماء وعناوين البقالات والمراكز المعتمدة لبيع الكروت.
4. **شاشة حالة الاتصال والمعلومات (`#status`)**:
   - اسم المستخدم المتصل.
   - مؤشر دائري لنسبة الاستهلاك المتبقية.
   - عداد التحميل (Download) والرفع (Upload) بوحدات عربية ذكية.
   - الوقت المتبقي، ومتصل منذ (Uptime).
   - خيار تغيير السرعة الفوري، ومفتاح تحديثات جوجل.
   - زري "تسجيل الخروج" و"قطع الاتصال"، وزر التواصل مع الدعم.
5. **شاشة الحظر (`#block`)**:
   - شاشة تنبيه الحظر المؤقت مع عداد تنازلي حي.

## 11. دليل التثبيت والرفع على راوتر المايكروتك

1. **تحضير المجلد**:
   - تأكد من وجود ملفات الصفحة كاملة داخل مجلد واحد باسم (مثلاً `hotspot` أو `alawla`).
2. **رفع الملفات إلى المايكروتك**:
   - افتح برنامج **WinBox** واتصل بالراوتر.
   - اذهب إلى القائمة: `Files`.
   - اسحب وأفلت مجلد الصفحة بالكامل إلى نافذة `Files` داخل مسار الهوتسبوت (مثل `flash/hotspot` أو `hotspot`).
3. **تفعيل الصفحة في الهوتسبوت**:
   - اذهب إلى: `IP` -> `Hotspot` -> `Server Profiles`.
   - افتح البروفايل الخاص بشبكتك (مثل `hsprof1`).
   - في خانة **HTML Directory**، اختر اسم المجلد الذي قمت برفعه.
   - في تبويب **Login**، تأكد من تفعيل: `HTTP PAP` و `HTTP CHAP` و `Cookie`.
   - اضغط **Apply** ثم **OK**.
4. **تعديل البيانات مستقبلاً**:
   - افتح ملف `dash.html` في متصفحك.
   - عدل الأسعار أو السرعات أو الإعلانات.
   - اضغط "تحميل الملف" واستبدل ملف `config.js` القديم في راوتر المايكروتك فقط دون الحاجة لإعادة رفع كامل الملفات.
