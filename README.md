# 📡 بوابة الأولى نت (MikroTik Hotspot Portal)

بوابة هوتسبوت تفاعلية حديثة وسريعة لراوترات مايكروتك (MikroTik RouterOS) مع دعم كامل لاختيار السرعات، حظر التحديثات، لوحة تحكم إدارية (`dash.html`)، وعرض استهلاك الرصيد وحالة الاتصال.

## 🚀 التثبيت السريع على المايكروتك:
1. انسخ ملفات البوابة إلى مجلد الهوتسبوت في الراوتر (عبر Winbox -> Files أو FTP).
2. تأكد من تحديد مسار المجلد في `/ip hotspot profile`.
3. لتعديل الأسعار والسرعات بدون أكواد: افتح `dash.html` في المتصفح، عدّل البيانات، ثم احفظ `config.js` في مجلد البوابة.

## 📁 ملفات القالب الأساسية:
- `index.html`: واجهة الهوتسبوت الرئيسية وتطبيق الـ SPA التفاعلي.
- `login.html`, `status.html`, `alogin.html`, `logout.html`: قوالب المصادقة المباشرة لمايكروتك.
- `config.js`: ملف الإعدادات والأسعار ونقاط البيع.
- `dash.html`: لوحة التحكم الإدارية المستقلة لمدير الشبكة.
- `fonts/`, `css/`, `js/`, `img/`: الأصول والملفات الخدمية المحسنة والمضغوطة.
